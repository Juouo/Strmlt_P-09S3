# Strmlt_P-09S3
Rice Leaf Care adalah aplikasi berbasis AI dan Computer Vision yang menggunakan MobileNetV2 untuk mendeteksi penyakit daun padi melalui foto. Aplikasi ini mengidentifikasi jenis penyakit serta menyediakan informasi gejala, penyebab, dan penanganan awal untuk membantu petani menjaga kesehatan tanaman padi.
